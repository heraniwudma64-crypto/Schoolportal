# School Management Portal

Full-stack project structure for a school management system.

## Architecture

- **Frontend:** React + TypeScript + Vite
- **Backend:** NestJS + TypeScript
- **Database:** PostgreSQL through Supabase
- **ORM:** Prisma

## Development

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run start:dev
```
